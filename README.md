# ZaraCatch 🛍️

ZaraCatch is an automation project that allows users to track and purchase Zara products automatically based on product codes and size preferences. After entering login credentials, product codes, and desired sizes, the bot searches for the products, adds them to the cart if available, and proceeds to the checkout step.

The goal of this project is to increase the chance of purchasing limited-stock Zara products while saving time.

---

## Features

- Automatic Zara login with email and password  
- Search products using product codes  
- Select desired size (e.g., M, L, 46, etc.)  
- Automatically add available products to cart  
- Proceed to checkout page  
- Works for clothing and footwear products  

---

## Technologies Used

- Programming Language: Python  
- Automation Library: Selenium  
- IDE: PyCharm  
- Web Driver: ChromeDriver  
- Environment Variables: python-dotenv  

---

## Environment Setup

- This project requires a `.env` file in the root directory.  
- Create a file named `.env` and add:
  EMAIL=YOUR_EMAIL_HERE
  PASSWORD=YOUR_PASSWORD_HERE
- Never share your real email or password.  
- Do not upload the `.env` file to GitHub.  
- Make sure `.env` is listed in your `.gitignore` file.

---

## Application Availability

The application runs locally using Selenium and can be executed directly from PyCharm.  
It is intended for personal automation and testing purposes.
